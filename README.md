# 🎯 YOLO26 Vision AI - Real-Time Web Object Detection

A real-time, AI-powered object detection web application using the **YOLO26 model**, with live webcam and mobile camera support.

- 📷 **Webcam & Mobile Camera Support** – Real-time object detection directly through your camera.
- ⚡ **High-Speed Detection** – Fast and efficient object detection powered by the YOLO26 Nano model.
- 🇹🇷 / 🇬🇧 **Multilingual Support** – Available in both Turkish and English.
- 🌙 / ☀️ **Dark & Light Mode** – Switch between dark and light themes.
- 📸 **Live HUD & Screenshot Capture** – Interactive real-time detection overlay with the ability to capture and save screenshots.
